Designed like a real AI system.

The repository separates ingestion, retrieval, generation, UI, API and deployment concerns so the project can evolve without becoming a single-file prototype.

📄

Document ingestion

Loads PDF, DOCX, TXT and Markdown into a normalized text pipeline.

🧩

Chunking pipeline

Splits long content into overlapping chunks so useful context survives retrieval.

🔎

Semantic retrieval

Ranks document chunks by similarity so answers are grounded in relevant evidence.

🧠

Local LLM core

The full local build uses Ollama for embeddings and generation without a paid cloud key.

📚

Citation-first answers

Responses are designed to include the source context used to support the answer.

⚙️

API + UI separation

FastAPI and Streamlit sit above a reusable core RAG package and testable modules.

Retrieval flow

A simple architecture with clear boundaries between documents, embeddings, retrieval and generation.

Security-first deployment surface

The Vercel-facing demo is intentionally static and secret-free. The full local RAG runtime remains separate, reducing cloud attack surface while keeping the portfolio experience live.

🛡️

Hardened browser policy

Security headers restrict framing, content types, referrers, browser permissions and cross-origin behavior.

🔐

No browser secrets

No API keys, tokens or credentials are embedded in the demo. User input is processed locally in the page and is not transmitted.
